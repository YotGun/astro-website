# Wooting 60HE (Tofu Redux Case)

The Wooting 60HE is probably my most exciting purchase of any gaming peripheral I've ever owned, ever. This tech was completely new and absolutely gamebreaking especially in the osu! community which I (regrettably) was a part of for a little while. I modded this board with the Red Tofu Redux case and Gateron Jade switches which improved the sound immensely.

## Specs (Stock)

- Layout: 60%
- Switches: Gateron Lekker switches (40gf - 60gf)
- Polling Rate: 1k
- Dimensions: 30.2 × 11.6 × 3.8 cm
- Weight: 605g

## What's special about this board?

The 60HE came with magnetic (hall effect) switches which works differently from regular switches. Instead of having physical contacts, each keyboard switch contains a little magnet inside and the PCB has sensors which senses how far away the magnets are. Combine those two things and essentially you have an analog keyboard similar to controller triggers. This also allows the keyboard to know right when you press / release the switch which gives you variable actuation points. This made counter-strafing in FPS games or streaming in osu! so much more responsive and instant.

## Conclusion

For something this revolutionary in the keyboard space, the price was justifiable for me. I spent around 240 CAD for this keyboard on release. However, I would not spend this money on this keyboard today, as a lot of competitors, especially in the Chinese market, have better build quality and performance for a lower price. This keyboard was a 9/10 but I've lowered it to a 7/10 due to the price. You should checkout the Wooting 60HE V2 or the 80HE instead if you are set on purchasing a Wooting.
