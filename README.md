# Personal Website

My personal website and portfolio, built with Astro and deployed on Cloudflare Workers.

The website contains information about me, my projects, interests, and experience as a Computing Science student at the University of Alberta.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/YotGun/astro-website.git
cd astro-website
```

Install the dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Or if you'd like to expose the server:
```bash
npm run dev -- --host
```

The website will be available at:

```text
http://localhost:4321
```

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

### Deploy

The project is configured for deployment to Cloudflare Workers.

```bash
npm run build
npm run deploy
```
